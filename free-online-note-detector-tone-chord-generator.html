Online Note Detector, Key & Scale Detector, Tone Generator and Chord Generator

This browser tool uses microphone pitch analysis for monophonic notes, a rolling note-history model to estimate major/minor key and scale, and the Web Audio API to synthesize reference tones and common chords. No audio file or account is required.

Pitch reference, note detection and chord practice

Use the microphone to estimate live musical notes, generate reference tones and play common chords directly in the browser. These features are useful for tuning practice, ear training and quick harmonic reference, while microphone quality and room noise can affect detection accuracy.

When this tool is useful

A note detector can help with tuning, ear training, checking a sung note or matching an instrument to a reference tone. Tone and chord generators are also useful for practising intervals and comparing harmonic relationships.

Practical limits and quality checks

Microphone quality, room noise, vibrato and complex overtones can affect detection. Use a clean sustained sound when possible and treat the displayed note as guidance rather than a laboratory-grade frequency measurement.

Privacy and responsible use

Microphone-based detection uses audio input while the feature is active, and generated tones are produced by the browser. Grant microphone access only when you intend to use live detection and revoke it later in browser settings if desired.

Frequently asked questions

Can browser audio processing change sound quality?

Live note detection analyses incoming sound and does not modify the instrument or microphone source. Generated reference tones are synthetic; keep playback at a comfortable level, particularly with headphones.

Why can results differ between browsers or devices?

Pitch readings depend on microphone quality, background noise, room acoustics and how stable the played note is. A quiet environment and sustained single notes generally produce more useful results than chords or noisy signals.
