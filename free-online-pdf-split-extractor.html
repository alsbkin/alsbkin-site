Split a PDF and Extract Pages

Create a new PDF from selected pages of an existing document directly in your browser. Use the tool when you need only a chapter, form, range of pages or specific pages instead of sharing the complete source file. Load the PDF, choose the pages you want to keep and export the extracted result.

Check page numbers carefully before creating the new document, especially when the PDF has cover pages or unnumbered introductory material that makes displayed page numbers differ from printed numbers. Extraction creates a separate PDF from the selected pages; it does not alter the original file on your device. Large or image-heavy PDFs can require additional browser memory while they are processed.

Processing is local, so the document does not need to be uploaded to a remote processing server. If you want to change page order rather than remove pages, use the PDF Page Organizer. For sideways pages use the PDF Rotator, and when several separate PDFs need to become one document use the PDF Merger.
