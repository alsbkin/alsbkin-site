Compress a PDF in Your Browser

Reduce the size of a PDF when you need a lighter document for sharing, storage or upload limits. Select the PDF, choose the available compression settings and create a smaller copy while keeping the original file unchanged on your device.

PDF size can come from images, embedded resources and document structure, so the amount of reduction varies from file to file. A document dominated by high-resolution images may offer more room for compression than a compact text-only PDF. Stronger compression can also affect visual quality, so check the resulting document before using it as your final copy. Pages, text and graphics should also be reviewed after processing when the document is important.

The tool is intended for convenient browser-based processing and works locally rather than requiring you to upload the PDF to a remote processing server. If file size is already acceptable and you only need selected pages, use the PDF Split & Page Extractor. To combine documents instead, use the PDF Merger.
