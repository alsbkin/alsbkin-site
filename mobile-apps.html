Mobile software developed under the ALSBKIN project. The current documented Android application is ALSBKIN Follow Balance, a utility for reviewing Instagram Followers and Following JSON exports on your device.

📱 ALSBKIN FOLLOW BALANCE

An Android utility for importing Instagram Followers and Following JSON files that you request and download from Instagram, then working through the resulting profile lists in a structured follow-balance workflow.

ANDROID • LOCAL DATA PROCESSING

The app does not request your Instagram password and does not upload the imported Followers or Following data to ALSBKIN servers. Read the app privacy details.

🛠️ HOW THE APP WORKS

Follow Balance stores workflow information locally so you can continue from where you left off. It can open Instagram profiles for manual review and can use an optional Android overlay for navigation controls.

NO INSTAGRAM PASSWORD REQUIRED

Imported JSON data and workflow state remain under the user’s control on the device. Local app data can be removed from Android settings or by uninstalling the application.

ALSBKIN Follow Balance for Android

ALSBKIN Follow Balance is designed around Instagram data exports supplied by the user rather than account credentials. The app reads Followers and Following JSON files locally to help organise a manual review workflow.

The application is independent and is not affiliated with, endorsed by or sponsored by Instagram or Meta. Its privacy model, locally stored workflow data, overlay permission and deletion options are described in the Privacy Policy.

About ALSBKIN mobile utilities

The mobile-app section documents utilities connected with the ALSBKIN project. App pages are intended to explain the purpose of each application, the permissions it may request and what information remains on the user’s device. An app should be evaluated by what it actually accesses rather than by broad assumptions about its category.

Permissions such as overlays, notifications, file access or network access can have legitimate functions, but they should still be understandable to the user. The site-wide Privacy Policy explains general data practices, while app-specific notes should be read whenever a mobile application has additional behaviour that does not apply to normal website browsing.
